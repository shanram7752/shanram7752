## 🚀 FEATURED PROJECTS

### 🌍 Geospatial Projects

**West Bengal 2026 Election — Results & Swing Analytics**
Geospatial analysis of the 2026 West Bengal Assembly Election — party performance, winning margins, and constituency-level 2021→2026 vote-swing mapping using choropleths.
`Python` `GeoPandas/Folium` `Pandas` `Choropleth Mapping`
**Key Focus:** Turns raw, tabular election results into spatial insight by joining results to constituency boundaries and visualizing shifts between two elections.
[![View Project](https://img.shields.io/badge/VIEW_PROJECT-6C2BD9?style=for-the-badge&logo=github&logoColor=white)](https://github.com/shanram7752/west-bengal-2026-election-analytics)

**Meghalaya Smart Tourism Platform (STIS)**
Interactive WebGIS Smart Tourist Information System for Meghalaya — routing, offbeat-site scoring, nearby-facility discovery, and a tourism dashboard.
`JavaScript` `Leaflet.js` `WebGIS` `Geospatial`
**Key Focus:** Applies GIS/geospatial scoring logic to real-world tourism planning, built for my MSc dissertation on Meghalaya's geotourism potential.
[![View Project](https://img.shields.io/badge/VIEW_PROJECT-6C2BD9?style=for-the-badge&logo=github&logoColor=white)](https://github.com/shanram7752/meghalaya-smart-tourism-platform)
[![Live Demo](https://img.shields.io/badge/LIVE_DEMO-2563EB?style=for-the-badge&logo=googlechrome&logoColor=white)](https://meghalayasmarttourismplatform.tiiny.site/)

### 📈 Business Intelligence

**Telecom Customer Churn Analysis & Prediction**
End-to-end Data Analytics + Machine Learning + Business Intelligence project on the IBM/Kaggle Telco Churn dataset — built with KNIME (cleaning, feature engineering, modelling) and Power BI (executive dashboard), verified in Python.
`KNIME` `Power BI` `Python` `Logistic Regression / Decision Tree / Random Forest`
**Key Focus:** Rebuilds and audits an earlier churn workflow, then turns the corrected model into a business-facing dashboard with KPIs and retention recommendations.
[![View Project](https://img.shields.io/badge/VIEW_PROJECT-6C2BD9?style=for-the-badge&logo=github&logoColor=white)](https://github.com/shanram7752/telecom-customer-churn-analysis)

**Retail Customer Segmentation (K-Means)**
Segments 200 retail customers via K-Means clustering on income and spending score, with cluster profiles translated into marketing recommendations.
`Python` `scikit-learn` `Unsupervised Learning`
**Key Focus:** Converts an unsupervised ML output into plain-language customer segments a marketing team could actually act on.
[![View Project](https://img.shields.io/badge/VIEW_PROJECT-6C2BD9?style=for-the-badge&logo=github&logoColor=white)](https://github.com/shanram7752/customer-segmentation-kmeans)
